# Автоматизация обработки обращений клиентов — ООО «Акцент Плюс»

Учебная работа: два отчёта по производственной практике и демонстрационный стенд CRM.
Сайт: **https://arslan-ahmetjanov.github.io/uni-akcent-crm/**

## Что внутри

| Папка | Содержимое |
|---|---|
| `reports/` | Отчёты по преддипломной и технологической практике, PDF и DOCX |
| `demo/` | Демо-прототип CRM: работает в браузере, без сервера |
| `stand/` | Комплект для развёртывания EspoCRM на VPS: конфигурация, дамп базы, скрипты |
| `assets/` | Скриншоты стенда и схемы |

## Цифры

- 1 250 обращений в месяц, 15 000 в год
- 34 минуты на обращение до внедрения, 22 после
- экономия 3 000 часов в год, 1 566 тыс. руб.
- стоимость владения 32,5 тыс. руб. в год, окупаемость 1,5 месяца

## Технологии

- **EspoCRM** (AGPLv3) — учёт обращений, портал клиента, веб-формы
- **MySQL 8.0**, контейнеры Docker
- демо-прототип — ванильный JavaScript, данные в localStorage

## Развёртывание стенда

```bash
unzip stand/accent-crm-stand.zip -d crm && cd crm
cp .env.example .env        # задать пароли и SITE_URL
docker compose up -d        # 2–3 минуты
bash deploy/restore.sh      # демонстрационные данные из дампа
```

Требования: 2 vCPU, 2 ГБ памяти, Docker. Подробная инструкция — `deploy/README.md`
внутри архива.

В комплекте нет `config-internal.php` и `cache/`: контейнер создаёт их при первой
установке со своим ключом шифрования, поэтому ключ конкретной установки в архив
не попадает. Демо-дамп не содержит таблиц `auth_token` и `auth_log_record`.
Порт админки публикуется только на `127.0.0.1`, наружу — через обратный прокси.

После `restore.sh` учётные записи приходят из дампа, и пароль администратора
из `.env` уже не действует. Если нужны известные доступы — не восстанавливайте
дамп, а наполните стенд скриптом `seed_demo.py` (см. `README.md` внутри архива).
